# Installation Guide

## 📋 Requirements

- **OS:** Windows 10 64-bit (build 1909+) or Windows 11 (21H2+)
- **CPU:** Intel Core i5 / AMD Ryzen 5 or better
- **RAM:** 8 GB minimum, 16 GB recommended
- **GPU:** DirectX 11 compatible
- **Storage:** 100 MB free space
- **Privileges:** Administrator access (required for registry & service tweaks)

---
